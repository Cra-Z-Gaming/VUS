Connect Firebase to start

This chat needs a free Firebase project. It takes about five minutes.

  1. In the Firebase console, create a project and add a Web app.
  2. Open Build → Authentication, click Get started, and turn on the Email/Password provider.
  3. Open Build → Realtime Database and create a database.
  4. On its Rules tab, paste the contents of database.rules.json and publish.
  5. Copy your web app’s config into FIREBASE_CONFIG near the bottom of this file. Include the databaseURL.
  6. Serve the page over http(s), for example Firebase Hosting or a local server. Authentication does not work when you open the file directly.

The first account created becomes the owner.
